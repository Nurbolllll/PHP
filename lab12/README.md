# Лабораторная работа №12: CRUD-приложение с MySQL и PDO

**Вариант 1:** Библиотека (управление каталогом книг и выдача экземпляров).

## Описание проекта
Веб-приложение на PHP 8+ для управления каталогом книг с использованием расширения **PDO**, подготовленных запросов (`Prepared Statements`) и паттерна **Repository**.

### Реализованный функционал:
- Полный цикл **CRUD** (создание, просмотр карточки, список с поиском, сортировкой и пагинацией, редактирование, удаление).
- **Транзакционная операция (`issueBookWithAudit`):** атомарное уменьшение количества экземпляров книги и запись события в таблицу `audit_log` с откатом (`rollBack`) при сбое.
- **Безопасность:** защита от SQL-инъекций (параметризованные запросы и allowlist для `ORDER BY`), защита от XSS (`htmlspecialchars`), защита от CSRF-атак (проверка токена сессии для POST-запросов), разграничение прав пользователя БД.

## Структура проекта
- `database/schema.sql` — SQL-схема таблиц `books` и `audit_log` (InnoDB) и настройка прав пользователя.
- `public/index.php` — единая точка входа и маршрутизация.
- `src/Database/ConnectionFactory.php` — фабрика подключения к MySQL через PDO (`utf8mb4`, `ERRMODE_EXCEPTION`).
- `src/Repository/BookRepository.php` — инкапсуляция SQL-запросов и транзакций.
- `src/Validation/BookValidator.php` — серверная валидация входных данных.
- `templates/books/` — HTML-шаблоны интерфейса.
- `tests/run.php` — автоматические тесты сценариев (включая проверку `rollBack`).

## Запуск и проверка
1. Импортировать `database/schema.sql` в MySQL.
2. Установить автозагрузку Composer:
   ```bash
   composer install
   ```
3. Запустить автотесты:
   ```bash
   composer check
   ```
